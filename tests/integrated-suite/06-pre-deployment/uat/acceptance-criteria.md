# Acceptance Criteria — توقيع صاحب المنتج

## التعريف

هذا الملف هو الإثبات الرسمي على أن صاحب المنتج راجع نتائج UAT ووافق على الإصدار.

## معايير القبول الإجمالية

- [ ] كل سيناريوهات [scenarios.md](./scenarios.md) بحالة `pass` أو `partial-with-known-issue`
- [ ] لا توجد `fail` مفتوحة في UAT
- [ ] جميع `partial` لها issue مفتوحة في GitHub بـ tag `uat-followup`
- [ ] لا توجد ثغرات أمنية `critical` أو `high` غير مغلقة (من 01-security)
- [ ] الأداء عند الحمل المتوقع في حدود thresholds (من 02-performance)
- [ ] الانحدار النهائي 100% pass (من 04-regression)
- [ ] الاستكشاف وجد ≤ 2 high-severity issues (من 05-exploratory)
