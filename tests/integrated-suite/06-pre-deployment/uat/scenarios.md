# UAT Scenarios — User Acceptance Testing

## التعريف

اختبار القبول يُنفَّذه صاحب المنتج أو ممثل عنه. هدفه التحقق أن التطبيق **يلبي متطلبات الأعمال**، لا فقط أنه يعمل تقنياً.

## مَن يُنفِّذ

- صاحب المنتج (PM)
- مستخدم نهائي ممثل (إن أمكن)

## كيف يُسجَّل

كل سيناريو له:
- **Acceptance Criteria** (شرط القبول) — قابلة للقياس
- **Steps** (خطوات تنفيذ)
- **Expected Result** (النتيجة المتوقعة)
- **Actual Result** (النتيجة الفعلية)
- **Status** (`pass` / `fail` / `partial`)

## السيناريوهات

### UAT-001 — مستخدم جديد ينشئ حسابه ويبدأ مشروعاً

**Acceptance Criteria:**
- ينجح إنشاء الحساب في < 2 دقيقة
- المستخدم يرى dashboard فارغ بدون أخطاء
- يستطيع إنشاء أول مشروع بنقرة واحدة

**Steps:**
1. افتح الصفحة الرئيسية
2. اضغط "ابدأ"
3. أدخل بريد + كلمة مرور
4. أكمل التحقق
5. اضغط "إنشاء مشروع جديد"

**Expected:** الانتقال لصفحة المشروع الجديدة مع UI واضح

### UAT-002 — كاتب سيناريو يحلّل سيناريو 10 صفحات

**Acceptance Criteria:**
- التحليل يكتمل في < 60 ثانية
- النتيجة تحوي قائمة المشاهد والشخصيات والأماكن
- يمكن حفظ النتيجة وتصديرها

**Steps:**
1. افتح breakdown
2. الصق سيناريو بطول 10 صفحات
3. اضغط "تحليل"
4. انتظر النتيجة
5. اضغط "حفظ" ثم "تصدير PDF"

**Expected:** PDF صالح يفتح بدون أخطاء

**Actual:** _____________________

**Status:** ☐ pass ☐ fail ☐ partial

### UAT-003 — مخرج يستخدم cinematography studio

**Acceptance Criteria:**
- يستطيع وصف المشهد بنص عربي
- يحصل على اقتراحات لقطات منطقية
- يستطيع تعديل الاقتراحات

**Steps:**
1. افتح cinematography studio
2. اكتب وصف مشهد (3-4 جمل)
3. اضغط "اقترح لقطات"
4. عدّل لقطة واحدة
5. احفظ

**Expected:** اللقطات تظهر مع تفاصيل (نوع، حركة، إضاءة)

**Actual:** _____________________

**Status:** ☐ pass ☐ fail ☐ partial

### UAT-005 — مستخدم يستعيد عمله بعد crash

**Acceptance Criteria:**
- بعد crash، البيانات لا تُفقد
- إعادة الفتح تستعيد الحالة السابقة
- الـ undo history لا يضيع

**Steps:**
1. ابدأ تحرير في editor
2. اكتب 200 كلمة
3. أغلق المتصفح فجأة (Force quit)
4. أعد الفتح
5. تأكد البيانات موجودة

**Expected:** كل ما كُتب محفوظ

**Actual:** _____________________

**Status:** ☐ pass ☐ fail ☐ partial

### UAT-006 — أمان: محاولة وصول لمشروع مستخدم آخر

**Acceptance Criteria:**
- نقر URL مباشر لمشروع لا يملكه = 403/404
- لا يُسرَّب ID-enumeration

**Steps:**
1. سجل دخول كمستخدم A
2. خذ project URL
3. سجل خروج
4. سجل دخول كمستخدم B
5. الصق URL

**Expected:** صفحة "غير مصرح" أو 404 — لا يُكشف وجود المشروع

**Actual:** _____________________
