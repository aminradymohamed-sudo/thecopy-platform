# اختبار ميداني - actorai-arabic (استوديو الممثل الذكي)

## شروط التنفيذ
- **المتصفح**: Chromium أو Chrome Desktop
- **الدقة الابتدائية**: 1440×900
- **اللغة والسياق**: العربية، واجهة RTL
- **أدوات القياس**: DevTools فقط
- **مجلد الأدلة**: `artifacts/manual-e2e/actorai-arabic/`

## أدوات DevTools المطلوبة
- Elements: فحص DOM وaria-label وrole وplaceholder
- Accessibility pane أو Lighthouse: فحص الوصولية
- Console: تسجيل أخطاء JavaScript
- Network: تسجيل الطلبات والحالات والزمن
- Application: فحص LocalStorage وSessionStorage وIndexedDB وCookies
- Performance: قياس FCP وTBT وLong Tasks
- Memory أو Chrome Task Manager: فحص تسرب الذاكرة
- Downloads: التحقق من التصدير الحقيقي

## قواعد الحكم
- **ناجح**: تم تنفيذ التدفق كاملًا، وظهرت النتيجة المتوقعة بدليل
- **فاشل**: تم تنفيذ التدفق وظهر خطأ أو نقص أو سلوك مخالف
- **محجوب**: تعذر التنفيذ بسبب قيد خارجي حقيقي
- **غير موجود**: العنصر أو التدفق غير موجود في الواجهة

## الحالات المتخصصة (8 حالات)

### ACTOR-UX-01 — تحميل الاستوديو
**الخطوات:**
1. افتح `/actorai-arabic`
2. تحقق من ظهور واجهة الاستوديو، العنوان، وأدوات التدريب
3. سجّل أى شاشة تحميل طويلة

**المتوقع:** ظهور واجهة عربية واضحة دون أخطاء Console

---

### ACTOR-UX-02 — تحليل الصوت
**الخطوات:**
1. افتح أداة تحليل الصوت
2. امنح صلاحية الميكروفون من المتصفح
3. ابدأ التسجيل
4. تحدث بجملة عربية قصيرة
5. أوقف التسجيل
6. راقب المقاييس الصوتية (الطبقة، مستوى الصوت، سرعة الكلام، وضوح النطق)

**المتوقع:** تظهر مؤشرات صوتية أو رسالة واضحة إذا لم يتوفر الميكروفون

**الحجب المقبول:** عدم توفر جهاز ميكروفون أو رفض صلاحية المتصفح

---

### ACTOR-UX-03 — تحليل الكاميرا
**الخطوات:**
1. افتح أداة تحليل الأداء البصري
2. امنح صلاحية الكاميرا
3. ابدأ التحليل
4. حرّك الوجه والعينين أو وضعية الجسم
5. راقب نتائج التعبير أو العين أو الحركة

**المتوقع:** ظهور تحليل أو رسالة صلاحيات واضحة

---

### ACTOR-UX-04 — أدوات الحفظ
**الخطوات:**
1. أدخل نصًا تمثيليًا
2. فعّل تمرين الحفظ
3. جرّب إخفاء كلمات أو تكرار مقطع
4. تحقق من تتبع الأخطاء أو التقدم

**المتوقع:** تعمل أدوات الحفظ دون فقد النص

---

### ACTOR-UX-05 — Teleprompter / Self Tape
**الخطوات:**
1. افتح جناح السيلف تيب
2. أدخل نصًا
3. فعّل التمرير
4. غيّر السرعة وحجم الخط
5. جرّب بدء التسجيل إن وجد

**المتوقع:** النص يمر بسلاسة، ولا تتعطل الواجهة

---

### ACTOR-UX-06 — مدرب الصوت
**الخطوات:**
1. افتح مدرب الصوت
2. اختر تمرين تنفس أو نطق
3. شغّل التمرين
4. تحقق من ظهور التعليمات والنتيجة

**المتوقع:** تجربة التدريب واضحة، وتظهر رسائل نجاح/خطأ

---

### ACTOR-DATA-01 — حفظ جلسة تدريب
**الخطوات:**
1. نفّذ تمرينًا
2. افحص التخزين
3. أعد التحميل

**المتوقع:** تعود الجلسة أو يظهر سجل تدريبات

---

### ACTOR-VAL-01 — إدخال نص عربي طويل
**الخطوات:**
1. أدخل مشهدًا عربيًا طويلًا
2. استخدم أدوات الحفظ أو التلقين
3. راقب الأداء

**المتوقع:** لا انهيار ولا تشويه RTL
