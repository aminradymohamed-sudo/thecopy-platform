# اختبار ميداني - styleIST (CineFit)

## شروط التنفيذ
- **المتصفح**: Chromium أو Chrome Desktop
- **الدقة الابتدائية**: 1440×900
- **اللغة والسياق**: العربية، واجهة RTL
- **أدوات القياس**: DevTools فقط
- **مجلد الأدلة**: `artifacts/manual-e2e/styleIST/`

## أدوات DevTools المطلوبة
- Elements: فحص DOM وaria-label وrole وplaceholder
- Accessibility pane أو Lighthouse: فحص الوصولية
- Console: تسجيل أخطاء JavaScript
- Network: تسجيل الطلبات والحالات والزمن
- Application: فحص LocalStorage وSessionStorage وIndexedDB وCookies
- Performance: قياس FCP وTBT وLong Tasks
- Memory أو Chrome Task Manager: فحص تسرب الذاكرة
- Downloads: التحقق من التصدير الحقيقي

## قواعد الحكم
- **ناجح**: تم تنفيذ التدفق كاملًا، وظهرت النتيجة المتوقعة بدليل
- **فاشل**: تم تنفيذ التدفق وظهر خطأ أو نقص أو سلوك مخالف
- **محجوب**: تعذر التنفيذ بسبب قيد خارجي حقيقي
- **غير موجود**: العنصر أو التدفق غير موجود في الواجهة

## الحالات المتخصصة (12 حالة)

### STYLE-UX-01 — تحميل CineFit
**الخطوات:**
1. افتح `/styleIST`
2. تحقق من ظهور الشاشة الرئيسية والتنقل

**المتوقع:** ظهور الواجهة بشكل صحيح

---

### STYLE-UX-02 — وضع المخرج
**الخطوات:**
1. افتح Director Mode
2. املأ أسئلة التصميم الستة:
   - نوع المشروع
   - سياق المشهد
   - ملف الشخصية
   - الحالة النفسية
   - موقع التصوير
   - القيود الإنتاجية

**المتوقع:** النموذج لا يسمح بالإرسال قبل اكتمال البيانات المطلوبة

---

### STYLE-UX-03 — توليد تصميم احترافي
**الخطوات:**
1. أكمل النموذج
2. اضغط Generate أو ما يعادله
3. راقب الطلب إلى `/api/styleist/execute`
4. تحقق من ظهور:
   - عنوان اللوك
   - الوصف الدرامي
   - تفصيل الأزياء
   - المواد
   - لوحة الألوان
   - الملاحظات الإنتاجية

**المتوقع:** توليد تصميم كامل

---

### STYLE-UX-04 — معالجة الخطأ
**الخطوات:**
1. افصل الإنترنت
2. أرسل النموذج
3. تحقق من ظهور رسالة ودية لا تحتوي رسالة تقنية خام

**المتوقع:** رسالة خطأ واضحة للمستخدم

---

### STYLE-UX-05 — غرفة القياس
**الخطوات:**
1. افتح Fitting Room
2. ارفع صورة زي
3. اختر garment رئيسي
4. جرّب أوضاع:
   - ثابت
   - انسيابي
   - ثقيل
   - رطب

**المتوقع:** المحاكاة تعمل بشكل صحيح

---
