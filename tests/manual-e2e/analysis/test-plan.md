# اختبار ميداني - analysis (نظام المحطات السبع للتحليل الدرامي)

## شروط التنفيذ
- **المتصفح**: Chromium أو Chrome Desktop
- **الدقة الابتدائية**: 1440×900
- **اللغة والسياق**: العربية، واجهة RTL
- **أدوات القياس**: DevTools فقط
- **مجلد الأدلة**: `artifacts/manual-e2e/analysis/`

## أدوات DevTools المطلوبة
- Elements: فحص DOM وaria-label وrole وplaceholder
- Accessibility pane أو Lighthouse: فحص الوصولية
- Console: تسجيل أخطاء JavaScript
- Network: تسجيل الطلبات والحالات والزمن
- Application: فحص LocalStorage وSessionStorage وIndexedDB وCookies
- Performance: قياس FCP وTBT وLong Tasks
- Memory أو Chrome Task Manager: فحص تسرب الذاكرة
- Downloads: التحقق من التصدير الحقيقي

## قواعد الحكم
- **ناجح**: تم تنفيذ التدفق كاملًا، وظهرت النتيجة المتوقعة بدليل
- **فاشل**: تم تنفيذ التدفق وظهر خطأ أو نقص أو سلوك مخالف
- **محجوب**: تعذر التنفيذ بسبب قيد خارجي حقيقي
- **غير موجود**: العنصر أو التدفق غير موجود في الواجهة

## الحالات المتخصصة (7 حالات)

### ANALYSIS-UX-01 — تحميل واجهة المحطات
**الخطوات:**
1. افتح `/analysis`
2. راقب شاشة "جاري تحميل المحطات السبع" إن ظهرت
3. تأكد من ظهور textarea وزر بدء التحليل

**المتوقع:** لا تبقى الشاشة في تحميل دائم

---

### ANALYSIS-UX-02 — منع التحليل الفارغ
**الخطوات:**
1. اترك حقل النص فارغًا
2. اضغط "بدء التحليل"

**المتوقع:** تظهر رسالة مثل "يرجى إدخال نص للتحليل"

---

### ANALYSIS-UX-03 — تحليل نص قصير
**الخطوات:**
1. أدخل نصًا دراميًا من فقرتين
2. اضغط بدء التحليل
3. راقب ظهور النتائج

**المتوقع:** تظهر بطاقات نتائج تشمل اللوجلاين أو الشخصيات أو العلاقات

---

### ANALYSIS-UX-04 — تحليل نص طويل وRAG
**الخطوات:**
1. أدخل نصًا طويلاً
2. شغّل التحليل
3. راقب هل تظهر مؤشرات تقسيم النص أو ملخص RAG

**المتوقع:** لا يحدث انهيار مع النص الطويل

---

### ANALYSIS-UX-05 — إعادة التعيين
**الخطوات:**
1. نفّذ تحليلًا
2. اضغط Reset أو ما يعادله
3. تحقق من رجوع الحالة إلى البداية

**المتوقع:** رجوع الحالة إلى البداية

---

### ANALYSIS-DATA-01 — حفظ نتيجة التحليل
**الخطوات:**
1. نفّذ تحليلًا
2. افحص LocalStorage وIndexedDB
3. أعد التحميل

**المتوقع:** إمّا تعود النتيجة أو لا يوجد حفظ مصمم؛ تسجل النتيجة بدقة

---

### ANALYSIS-PERF-01 — زمن التحليل
**الخطوات:**
1. أدخل نصًا متوسطًا
2. سجّل زمن التحليل من الضغط حتى ظهور أول نتيجة

**المتوقع:** زمن مقبول للتحليل
