# اختبار ميداني - directors-studio (استوديو المخرجين)

## شروط التنفيذ
- **المتصفح**: Chromium أو Chrome Desktop
- **الدقة الابتدائية**: 1440×900
- **اللغة والسياق**: العربية، واجهة RTL
- **أدوات القياس**: DevTools فقط
- **مجلد الأدلة**: `artifacts/manual-e2e/directors-studio/`

## أدوات DevTools المطلوبة
- Elements: فحص DOM وaria-label وrole وplaceholder
- Accessibility pane أو Lighthouse: فحص الوصولية
- Console: تسجيل أخطاء JavaScript
- Network: تسجيل الطلبات والحالات والزمن
- Application: فحص LocalStorage وSessionStorage وIndexedDB وCookies
- Performance: قياس FCP وTBT وLong Tasks
- Memory أو Chrome Task Manager: فحص تسرب الذاكرة
- Downloads: التحقق من التصدير الحقيقي

## قواعد الحكم
- **ناجح**: تم تنفيذ التدفق كاملًا، وظهرت النتيجة المتوقعة بدليل
- **فاشل**: تم تنفيذ التدفق وظهر خطأ أو نقص أو سلوك مخالف
- **محجوب**: تعذر التنفيذ بسبب قيد خارجي حقيقي
- **غير موجود**: العنصر أو التدفق غير موجود في الواجهة

## الحالات المتخصصة (9 حالات)

### DIRECTOR-UX-01 — تحميل الاستوديو
**الخطوات:**
1. افتح `/directors-studio`
2. تحقق من ظهور الواجهة الرئيسية

**المتوقع:** ظهور الاستوديو بشكل صحيح

---

### DIRECTOR-UX-02 — التنقل بين الوحدات
**الخطوات:**
اختبر الوصول إلى:
- AI Assistant
- Characters
- Scenes
- Script
- Shots
- Shared أو أي تبويب قائم
- أي runtime pack أو Copilot متاح

**المتوقع:** كل وحدة تفتح دون أخطاء Console

---

### DIRECTOR-UX-03 — إدارة الشخصيات
**الخطوات:**
1. أضف شخصية
2. أدخل الاسم والدور والوصف
3. احفظ
4. أعد فتح الوحدة

**المتوقع:** الشخصية محفوظة

---

### DIRECTOR-UX-04 — إدارة المشاهد
**الخطوات:**
1. أضف مشهدًا
2. أضف عنوان مشهد ووصفًا
3. اربطه بشخصيات إن أمكن

**المتوقع:** حفظ المشهد بنجاح

---

### DIRECTOR-UX-05 — إدارة اللقطات
**الخطوات:**
1. أضف shot
2. حدد نوع اللقطة أو الزاوية
3. اربطها بمشهد

**المتوقع:** حفظ اللقطة بنجاح

---

### DIRECTOR-UX-06 — النص
**الخطوات:**
1. افتح script
2. أدخل نصًا
3. جرّب حفظه أو تحليله إن كان ذلك متاحًا

**المتوقع:** حفظ أو تحليل النص

---

### DIRECTOR-UX-07 — المساعد الذكي
**الخطوات:**
1. اطرح سؤالًا عن مشهد
2. تحقق من الرد

**المتوقع:** رد واضح من المساعد

---

### DIRECTOR-DATA-01 — حفظ مشروع المخرج
**الخطوات:**
1. أضف شخصية ومشهد ولقطة
2. أعد التحميل
3. تحقق من الاستعادة

**المتوقع:** استعادة جميع البيانات

---

### DIRECTOR-AUTH-01 — صلاحيات المخرج
**الخطوات:**
1. افتح المسار دون جلسة
2. جرّب تعديل البيانات

**المتوقع:** منع أو رسالة تسجيل دخول إذا كان التطبيق يتطلب مصادقة
