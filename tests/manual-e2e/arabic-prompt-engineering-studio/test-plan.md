# اختبار ميداني - arabic-prompt-engineering-studio (استوديو هندسة البرومبت)

## شروط التنفيذ
- **المتصفح**: Chromium أو Chrome Desktop
- **الدقة الابتدائية**: 1440×900
- **اللغة والسياق**: العربية، واجهة RTL
- **أدوات القياس**: DevTools فقط
- **مجلد الأدلة**: `artifacts/manual-e2e/arabic-prompt-engineering-studio/`

## أدوات DevTools المطلوبة
- Elements: فحص DOM وaria-label وrole وplaceholder
- Accessibility pane أو Lighthouse: فحص الوصولية
- Console: تسجيل أخطاء JavaScript
- Network: تسجيل الطلبات والحالات والزمن
- Application: فحص LocalStorage وSessionStorage وIndexedDB وCookies
- Performance: قياس FCP وTBT وLong Tasks
- Memory أو Chrome Task Manager: فحص تسرب الذاكرة
- Downloads: التحقق من التصدير الحقيقي

## قواعد الحكم
- **ناجح**: تم تنفيذ التدفق كاملًا، وظهرت النتيجة المتوقعة بدليل
- **فاشل**: تم تنفيذ التدفق وظهر خطأ أو نقص أو سلوك مخالف
- **محجوب**: تعذر التنفيذ بسبب قيد خارجي حقيقي
- **غير موجود**: العنصر أو التدفق غير موجود في الواجهة

## الحالات المتخصصة (7 حالات)

### PROMPT-UX-01 — إدخال وتحليل Prompt
**الخطوات:**
1. افتح `/arabic-prompt-engineering-studio`
2. اكتب prompt عربيًا
3. اضغط Analyze

**المتوقع:** تظهر نتيجة تحليل أو metrics أو suggestions

---

### PROMPT-UX-02 — منع التحليل الفارغ
**الخطوات:**
1. اترك prompt فارغًا
2. اضغط Analyze

**المتوقع:** لا يبدأ التحليل أو تظهر رسالة واضحة

---

### PROMPT-UX-03 — القوالب
**الخطوات:**
1. افتح تبويب القوالب
2. اختر قالبًا
3. املأ المتغيرات
4. تحقق من توليد prompt نهائي

**المتوقع:** توليد prompt بناءً على القالب والمتغيرات

---

### PROMPT-UX-04 — مقارنة Promptين
**الخطوات:**
1. أدخل Prompt أول
2. أدخل Prompt ثان
3. اضغط Compare
4. تحقق من ظهور winner أو tie والفروقات

**المتوقع:** ظهور نتيجة المقارنة والفروقات

---

### PROMPT-UX-05 — الاقتراحات
**الخطوات:**
1. حلل prompt
2. افتح suggestions
3. طبّق اقتراحًا إن كان الزر متاحًا

**المتوقع:** تطبيق الاقتراح على الـ prompt

---

### PROMPT-UX-06 — النسخ للحافظة
**الخطوات:**
1. اضغط Copy
2. الصق في حقل آخر
3. راقب Console

**المتوقع:** النسخ يعمل أو تظهر رسالة صلاحية حافظة واضحة

---

### PROMPT-DATA-01 — التاريخ
**الخطوات:**
1. حلل 3 prompts
2. أعد التحميل
3. تحقق من بقاء آخر 10 عناصر في التاريخ

**المتوقع:** حفظ التاريخ واستعادته
