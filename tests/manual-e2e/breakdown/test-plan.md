# اختبار ميداني - breakdown (BreakBreak AI)

## شروط التنفيذ
- **المتصفح**: Chromium أو Chrome Desktop
- **الدقة الابتدائية**: 1440×900
- **اللغة والسياق**: العربية، واجهة RTL
- **أدوات القياس**: DevTools فقط
- **مجلد الأدلة**: `artifacts/manual-e2e/breakdown/`

## أدوات DevTools المطلوبة
- Elements: فحص DOM وaria-label وrole وplaceholder
- Accessibility pane أو Lighthouse: فحص الوصولية
- Console: تسجيل أخطاء JavaScript
- Network: تسجيل الطلبات والحالات والزمن
- Application: فحص LocalStorage وSessionStorage وIndexedDB وCookies
- Performance: قياس FCP وTBT وLong Tasks
- Memory أو Chrome Task Manager: فحص تسرب الذاكرة
- Downloads: التحقق من التصدير الحقيقي

## قواعد الحكم
- **ناجح**: تم تنفيذ التدفق كاملًا، وظهرت النتيجة المتوقعة بدليل
- **فاشل**: تم تنفيذ التدفق وظهر خطأ أو نقص أو سلوك مخالف
- **محجوب**: تعذر التنفيذ بسبب قيد خارجي حقيقي
- **غير موجود**: العنصر أو التدفق غير موجود في الواجهة

## الحالات المتخصصة (10 حالات)

### BREAKDOWN-UX-01 — إدخال سيناريو
**الخطوات:**
1. افتح `/breakdown`
2. الصق نص سيناريو
3. اضغط Segment أو Analyze

**المتوقع:** تظهر قائمة مشاهد

---

### BREAKDOWN-UX-02 — تحليل مشهد
**الخطوات:**
1. اختر مشهدًا
2. شغّل analyzeScene
3. تحقق من ظهور:
   - cast
   - costumes
   - makeup
   - vehicles
   - locations
   - props
   - stunts
   - animals
   - spfx
   - vfx

**المتوقع:** تحليل كامل للمشهد

---

### BREAKDOWN-UX-03 — وكلاء التفكيك
**الخطوات:**
1. راقب AgentCards
2. تحقق من أن كل وكيل يعرض عناصر أو حالة فارغة واضحة

**المتوقع:** عرض واضح لكل وكيل

---

### BREAKDOWN-UX-04 — تحليل الشخصيات
**الخطوات:**
1. افتح CastBreakdown
2. جرّب البحث والتصفية والتصدير

**المتوقع:** عمليات البحث والتصفية تعمل

---

### BREAKDOWN-UX-05 — سيناريوهات إنتاج
**الخطوات:**
1. افتح Scenario Navigator
2. ولّد 3 سيناريوهات
3. تحقق من metrics:
   - budget
   - schedule
   - risk
   - creative

**المتوقع:** توليد سيناريوهات مع مقاييس

---

### BREAKDOWN-UX-06 — ChatBot
**الخطوات:**
1. افتح ChatBot
2. اسأل عن مشهد
3. تحقق من رد مفهوم

**المتوقع:** ردود واضحة ومفهومة

---

### BREAKDOWN-DATA-01 — تقرير LocalStorage
**الخطوات:**
1. نفّذ تحليلًا
2. افحص LocalStorage
3. أعد التحميل
4. تحقق من استعادة report أو scenes

**المتوقع:** حفظ واستعادة البيانات

---

### BREAKDOWN-DATA-03 — تصدير CSV/JSON
**الخطوات:**
1. صدّر cast
2. افحص الملفات

**المتوقع:** ملفات CSV/JSON صالحة

---

### BREAKDOWN-AUTH-01 — Gemini API Key
**الخطوات:**
1. شغّل تحليل بدون key
2. تحقق من رسالة "API key required" أو ما يعادلها

**المتوقع:** رسالة واضحة لعدم وجود API Key
