# اختبار ميداني - brain-storm-ai (نظام الوكلاء المتعدد)

## شروط التنفيذ
- **المتصفح**: Chromium أو Chrome Desktop
- **الدقة الابتدائية**: 1440×900
- **اللغة والسياق**: العربية، واجهة RTL
- **أدوات القياس**: DevTools فقط
- **مجلد الأدلة**: `artifacts/manual-e2e/brain-storm-ai/`

## أدوات DevTools المطلوبة
- Elements: فحص DOM وaria-label وrole وplaceholder
- Accessibility pane أو Lighthouse: فحص الوصولية
- Console: تسجيل أخطاء JavaScript
- Network: تسجيل الطلبات والحالات والزمن
- Application: فحص LocalStorage وSessionStorage وIndexedDB وCookies
- Performance: قياس FCP وTBT وLong Tasks
- Memory أو Chrome Task Manager: فحص تسرب الذاكرة
- Downloads: التحقق من التصدير الحقيقي

## قواعد الحكم
- **ناجح**: تم تنفيذ التدفق كاملًا، وظهرت النتيجة المتوقعة بدليل
- **فاشل**: تم تنفيذ التدفق وظهر خطأ أو نقص أو سلوك مخالف
- **محجوب**: تعذر التنفيذ بسبب قيد خارجي حقيقي
- **غير موجود**: العنصر أو التدفق غير موجود في الواجهة

## الحالات المتخصصة (8 حالات)

### BRAIN-UX-01 — بدء جلسة
**الخطوات:**
1. افتح `/brain-storm-ai`
2. أدخل فكرة إبداعية
3. اضغط بدء جلسة

**المتوقع:** تبدأ جلسة وتظهر مراحل العمل

---

### BRAIN-UX-02 — خمس مراحل
**الخطوات:**
1. راقب مراحل العمل
2. تحقق من انتقال الحالة بين المراحل الخمس

**المتوقع:** انتقال سلس بين المراحل

---

### BRAIN-UX-03 — حالة الوكلاء
**الخطوات:**
1. شغّل جلسة
2. راقب حالة كل agent
3. تحقق من عدم بقاء وكيل عالق في loading

**المتوقع:** عدم تعلّق الوكلاء في حالة loading

---

### BRAIN-UX-04 — رفع ملف TXT
**الخطوات:**
1. ارفع ملف TXT عربي
2. تحقق من قراءة المحتوى

**المتوقع:** قراءة ملف TXT بنجاح

---

### BRAIN-UX-05 — رفع PDF/DOCX
**الخطوات:**
1. ارفع PDF
2. ارفع DOCX
3. سجل إن كان parsing يعمل أو يظهر خطأ مفهوم

**المتوقع:** معالجة الملفات أو رسالة خطأ واضحة

---

### BRAIN-UX-06 — مناظرة متعددة الوكلاء
**الخطوات:**
1. أدخل سؤالًا
2. شغّل النقاش
3. تحقق من ظهور آراء متعددة ونتيجة مجمعة

**المتوقع:** ظهور آراء متعددة ونتيجة مجمعة

---

### BRAIN-DATA-01 — حفظ الجلسة
**الخطوات:**
1. أنشئ جلسة
2. أعد التحميل
3. تحقق من استعادة الجلسة أو سجلها

**المتوقع:** حفظ واستعادة الجلسة

---

### BRAIN-SESS-03 — مفاتيح Gemini
**الخطوات:**
1. افحص التخزين
2. تحقق من عدم تخزين مفاتيح API مكشوفة

**المتوقع:** عدم تخزين مفاتيح API مكشوفة
