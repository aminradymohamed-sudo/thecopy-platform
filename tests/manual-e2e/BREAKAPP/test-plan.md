# اختبار ميداني - BREAKAPP

## شروط التنفيذ
- **المتصفح**: Chromium أو Chrome Desktop
- **الدقة الابتدائية**: 1440×900
- **اللغة والسياق**: العربية، واجهة RTL
- **أدوات القياس**: DevTools فقط
- **مجلد الأدلة**: `artifacts/manual-e2e/BREAKAPP/`

## أدوات DevTools المطلوبة
- Elements: فحص DOM وaria-label وrole وplaceholder
- Accessibility pane أو Lighthouse: فحص الوصولية
- Console: تسجيل أخطاء JavaScript
- Network: تسجيل الطلبات والحالات والزمن
- Application: فحص LocalStorage وSessionStorage وIndexedDB وCookies
- Performance: قياس FCP وTBT وLong Tasks
- Memory أو Chrome Task Manager: فحص تسرب الذاكرة
- Downloads: التحقق من التصدير الحقيقي

## قواعد الحكم
- **ناجح**: تم تنفيذ التدفق كاملًا، وظهرت النتيجة المتوقعة بدليل
- **فاشل**: تم تنفيذ التدفق وظهر خطأ أو نقص أو سلوك مخالف
- **محجوب**: تعذر التنفيذ بسبب قيد خارجي حقيقي
- **غير موجود**: العنصر أو التدفق غير موجود في الواجهة

## الحالات المتخصصة (8 حالات)

### BREAK-UX-01 — الصفحة الرئيسية
**الخطوات:**
1. افتح `/BREAKAPP`
2. تحقق من التوجيه:
   - login
   - dashboard
   - role page

**المتوقع:** توجيه صحيح حسب حالة المصادقة

---

### BREAK-UX-02 — QR Login
**الخطوات:**
1. افتح `/BREAKAPP/login/qr`
2. جرّب إدخال QR غير صالح
3. سجّل رسالة الخطأ

**المتوقع:** رسالة خطأ واضحة لـ QR غير صالح

---

### BREAK-UX-03 — Dashboard
**الخطوات:**
1. سجّل الدخول إن توفرت بيانات اختبار
2. افتح Dashboard
3. تحقق من ظهور روابط حسب الدور

**المتوقع:** روابط مصممة حسب الدور

---

### BREAK-UX-04 — Director
**الخطوات:**
1. افتح `/BREAKAPP/director`
2. تحقق من أدوات الموقع والجلسة اليومية
3. جرّب إنشاء جلسة بموقع تصوير

**المتوقع:** أدوات المخرج متاحة وعملية

---

### BREAK-UX-05 — Crew Menu
**الخطوات:**
1. افتح `/BREAKAPP/crew/menu`
2. اختر vendor
3. أضف عناصر إلى السلة
4. أرسل طلبًا

**المتوقع:** عملية الطلب تكتمل بنجاح

### BREAK-UX-06 — Runner Track
**الخطوات:**
1. افتح `/BREAKAPP/runner/track`
