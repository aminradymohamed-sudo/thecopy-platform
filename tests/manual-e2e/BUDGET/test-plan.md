# اختبار ميداني - BUDGET (FilmBudget AI Pro)

## شروط التنفيذ
- **المتصفح**: Chromium أو Chrome Desktop
- **الدقة الابتدائية**: 1440×900
- **اللغة والسياق**: العربية، واجهة RTL
- **أدوات القياس**: DevTools فقط
- **مجلد الأدلة**: `artifacts/manual-e2e/BUDGET/`

## أدوات DevTools المطلوبة
- Elements: فحص DOM وaria-label وrole وplaceholder
- Accessibility pane أو Lighthouse: فحص الوصولية
- Console: تسجيل أخطاء JavaScript
- Network: تسجيل الطلبات والحالات والزمن
- Application: فحص LocalStorage وSessionStorage وIndexedDB وCookies
- Performance: قياس FCP وTBT وLong Tasks
- Memory أو Chrome Task Manager: فحص تسرب الذاكرة
- Downloads: التحقق من التصدير الحقيقي

## قواعد الحكم
- **ناجح**: تم تنفيذ التدفق كاملًا، وظهرت النتيجة المتوقعة بدليل
- **فاشل**: تم تنفيذ التدفق وظهر خطأ أو نقص أو سلوك مخالف
- **محجوب**: تعذر التنفيذ بسبب قيد خارجي حقيقي
- **غير موجود**: العنصر أو التدفق غير موجود في الواجهة

## الحالات المتخصصة (10 حالات)

### BUDGET-UX-01 — إدخال عنوان وسيناريو
**الخطوات:**
1. افتح `/BUDGET`
2. أدخل عنوان الفيلم
3. أدخل سيناريو أو وصف

**المتوقع:** قبول البيانات المدخلة

---

### BUDGET-UX-02 — تحليل متقدم
**الخطوات:**
1. اضغط Advanced Analysis
2. تحقق من ظهور:
   - المتطلبات الإنتاجية
   - المخاطر
   - التوصيات

**المتوقع:** تحليل متقدم مع التفاصيل

---

### BUDGET-UX-03 — إنشاء الميزانية
**الخطوات:**
1. اضغط "إنشاء الميزانية الكاملة"
2. انتظر
3. تحقق من ظهور جدول بنود الميزانية

**المتوقع:** جدول بنود الميزانية كامل

---

### BUDGET-UX-04 — تعديل بند
**الخطوات:**
1. غيّر تكلفة بند
2. تحقق من تحديث الإجمالي

**المتوقع:** تحديث تلقائي للإجمالي

---

### BUDGET-UX-05 — الرسوم البيانية
**الخطوات:**
1. افتح BudgetAnalytics
2. راقب chart hover والتحديث

**المتوقع:** رسوم بيانية تفاعلية

---

### BUDGET-UX-06 — القوالب
**الخطوات:**
1. افتح TemplateSelector
2. اختر قالبًا
3. تحقق من تغير structure

**المتوقع:** تطبيق القالب بنجاح

---

### BUDGET-UX-07 — التصدير
**الخطوات:**
1. صدّر PDF
2. صدّر Excel
3. افحص الملفين

**المتوقع:** ملفات PDF وExcel صالحة

---

### BUDGET-DATA-01 — حفظ واستعادة المشروع
**الخطوات:**
1. أنشئ ميزانية
2. أعد التحميل
3. تحقق من الاستعادة

**المتوقع:** حفظ واستعادة المشروع

---

### BUDGET-AUTH-01 — Gemini API Key
**الخطوات:**
1. شغّل generation بدون key
2. تحقق من رسالة واضحة لا تكشف أسرارًا

**المتوقع:** رسالة واضحة لعدم وجود API Key

---

### BUDGET-VAL-03 — اسم ملف خطر
**الخطوات:**
1. استخدم عنوان فيلم: `../../../etc/passwd`
2. صدّر
3. تحقق من تعقيم اسم الملف

**المتوقع:** تعقيم اسم الملف
