# اختبار ميداني - art-director (CineArchitect)

## شروط التنفيذ
- **المتصفح**: Chromium أو Chrome Desktop
- **الدقة الابتدائية**: 1440×900
- **اللغة والسياق**: العربية، واجهة RTL
- **أدوات القياس**: DevTools فقط
- **مجلد الأدلة**: `artifacts/manual-e2e/art-director/`

## أدوات DevTools المطلوبة
- Elements: فحص DOM وaria-label وrole وplaceholder
- Accessibility pane أو Lighthouse: فحص الوصولية
- Console: تسجيل أخطاء JavaScript
- Network: تسجيل الطلبات والحالات والزمن
- Application: فحص LocalStorage وSessionStorage وIndexedDB وCookies
- Performance: قياس FCP وTBT وLong Tasks
- Memory أو Chrome Task Manager: فحص تسرب الذاكرة
- Downloads: التحقق من التصدير الحقيقي

## قواعد الحكم
- **ناجح**: تم تنفيذ التدفق كاملًا، وظهرت النتيجة المتوقعة بدليل
- **فاشل**: تم تنفيذ التدفق وظهر خطأ أو نقص أو سلوك مخالف
- **محجوب**: تعذر التنفيذ بسبب قيد خارجي حقيقي
- **غير موجود**: العنصر أو التدفق غير موجود في الواجهة

## الحالات المتخصصة (6 حالات)

### ART-UX-01 — التنقل الرئيسي
**الخطوات:**
1. افتح `/art-director`
2. انتقل بين:
   - لوحة التحكم
   - جميع الأدوات
   - الإلهام البصري
   - المواقع
   - الديكورات
   - الإنتاجية
   - التوثيق

**المتوقع:** كل تبويب يغيّر المحتوى

---

### ART-UX-02 — حفظ التبويب النشط
**الخطوات:**
1. افتح تبويب غير Dashboard
2. أعد التحميل
3. تحقق من رجوع نفس التبويب أو وجود query param صحيح

**المتوقع:** حفظ وحفظ التبويب النشط

---

### ART-UX-03 — جميع الأدوات
**الخطوات:**
1. افتح Tools
2. اختر أداة
3. املأ الحقول
4. اضغط Execute

**المتوقع:** تظهر نتيجة أو رسالة فشل خادم واضحة

---

### ART-UX-04 — fallback المحلي
**الخطوات:**
1. افصل الإنترنت من DevTools
2. نفذ أداة visual analyzer إن وجدت
3. تحقق من ظهور fallback local result إن كان مصممًا

**المتوقع:** ظهور fallback محلي

---

### ART-DATA-01 — حفظ نماذج الأدوات
**الخطوات:**
1. أدخل بيانات في أداة
2. انتقل لتبويب آخر
3. عد للأداة

**المتوقع:** البيانات تبقى إذا كان التخزين مصممًا لذلك

---

### ART-VAL-01 — مدخلات أداة غير آمنة
**الخطوات:**
1. أدخل HTML/JS في حقل أداة
2. نفّذ
3. تحقق من عدم تنفيذ الشيفرة

**المتوقع:** عدم تنفيذ الشيفرة الضارة
