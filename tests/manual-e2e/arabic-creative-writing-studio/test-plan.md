# اختبار ميداني - arabic-creative-writing-studio (استوديو الكتابة الإبداعية)

## شروط التنفيذ
- **المتصفح**: Chromium أو Chrome Desktop
- **الدقة الابتدائية**: 1440×900
- **اللغة والسياق**: العربية، واجهة RTL
- **أدوات القياس**: DevTools فقط
- **مجلد الأدلة**: `artifacts/manual-e2e/arabic-creative-writing-studio/`

## أدوات DevTools المطلوبة
- Elements: فحص DOM وaria-label وrole وplaceholder
- Accessibility pane أو Lighthouse: فحص الوصولية
- Console: تسجيل أخطاء JavaScript
- Network: تسجيل الطلبات والحالات والزمن
- Application: فحص LocalStorage وSessionStorage وIndexedDB وCookies
- Performance: قياس FCP وTBT وLong Tasks
- Memory أو Chrome Task Manager: فحص تسرب الذاكرة
- Downloads: التحقق من التصدير الحقيقي

## قواعد الحكم
- **ناجح**: تم تنفيذ التدفق كاملًا، وظهرت النتيجة المتوقعة بدليل
- **فاشل**: تم تنفيذ التدفق وظهر خطأ أو نقص أو سلوك مخالف
- **محجوب**: تعذر التنفيذ بسبب قيد خارجي حقيقي
- **غير موجود**: العنصر أو التدفق غير موجود في الواجهة

## الحالات المتخصصة (11 حالة)

### CREATIVE-UX-01 — الصفحة الرئيسية
**الخطوات:**
1. افتح `/arabic-creative-writing-studio`
2. تحقق من ظهور رأس الاستوديو وقائمة المشاريع

**المتوقع:** ظهور واجهة الاستوديو بشكل صحيح

---

### CREATIVE-UX-02 — إنشاء مشروع جديد
**الخطوات:**
1. اضغط "مشروع جديد"
2. تحقق من فتح المحرر
3. اكتب عنوانًا ونصًا

**المتوقع:** المشروع يظهر في الحالة الحالية

---

### CREATIVE-UX-03 — حفظ المشروع
**الخطوات:**
1. اكتب نصًا
2. اضغط حفظ
3. سجّل نص Toast

**المتوقع:** رسالة حفظ واضحة، وظهور المشروع في القائمة

---

### CREATIVE-UX-04 — فتح مشروع محفوظ
**الخطوات:**
1. ارجع للرئيسية
2. افتح المشروع
3. تحقق من عودة العنوان والمحتوى

**المتوقع:** عودة بيانات المشروع كما كانت

---

### CREATIVE-UX-05 — المكتبة
**الخطوات:**
1. افتح Library
2. اختر Prompt
3. تحقق من إنشاء مشروع مرتبط بالمحفز

**المتوقع:** إنشاء مشروع جديد مرتبط بالمحفز المختار

---

### CREATIVE-UX-06 — التحدي اليومي/الأسبوعي
**الخطوات:**
1. شغّل Daily Prompt أو Weekly Challenge
2. تحقق من فتح محرر جديد به prompt أو tags

**المتوقع:** فتح محرر جديد محمل بالتحدي

---

### CREATIVE-UX-07 — تحليل النص بدون Gemini Key
**الخطوات:**
1. افتح المحرر
2. اكتب نصًا
3. اضغط تحليل

**المتوقع:** تظهر رسالة واضحة أن التحليل يحتاج مفتاح Gemini صالحًا

---

### CREATIVE-UX-08 — تحليل النص مع Gemini Key
**الخطوات:**
1. افتح Settings
2. أضف مفتاح اختبار في بيئة آمنة
3. اختبر الاتصال
4. شغّل التحليل

**المتوقع:** يعمل التحليل أو تظهر رسالة اتصال واضحة

---

### CREATIVE-UX-09 — التصدير
**الخطوات:**
1. افتح مشروعًا
2. جرّب كل صيغة تصدير متاحة
3. افحص ملفات Downloads

**المتوقع:** ظهور ملفات التصدير بشكل صحيح

---

### CREATIVE-DATA-01 — الاستعادة
**الخطوات:**
1. اكتب نصًا فريدًا
2. أعد التحميل
3. تحقق من رجوعه

**المتوقع:** استعادة النص المكتوب

---

### CREATIVE-SESS-03 — مفاتيح Gemini
**الخطوات:**
1. افحص LocalStorage
2. ابحث عن geminiApiKey

**المتوقع:** إذا وجد المفتاح مكشوفًا، يسجل كخطر أمني
