# اختبار ميداني - cinematography-studio (CineAI Vision)

## شروط التنفيذ
- **المتصفح**: Chromium أو Chrome Desktop
- **الدقة الابتدائية**: 1440×900
- **اللغة والسياق**: العربية، واجهة RTL
- **أدوات القياس**: DevTools فقط
- **مجلد الأدلة**: `artifacts/manual-e2e/cinematography-studio/`

## أدوات DevTools المطلوبة
- Elements: فحص DOM وaria-label وrole وplaceholder
- Accessibility pane أو Lighthouse: فحص الوصولية
- Console: تسجيل أخطاء JavaScript
- Network: تسجيل الطلبات والحالات والزمن
- Application: فحص LocalStorage وSessionStorage وIndexedDB وCookies
- Performance: قياس FCP وTBT وLong Tasks
- Memory أو Chrome Task Manager: فحص تسرب الذاكرة
- Downloads: التحقق من التصدير الحقيقي

## قواعد الحكم
- **ناجح**: تم تنفيذ التدفق كاملًا، وظهرت النتيجة المتوقعة بدليل
- **فاشل**: تم تنفيذ التدفق وظهر خطأ أو نقص أو سلوك مخالف
- **محجوب**: تعذر التنفيذ بسبب قيد خارجي حقيقي
- **غير موجود**: العنصر أو التدفق غير موجود في الواجهة

## الحالات المتخصصة (11 حالة)

### CINE-UX-01 — اختيار المزاج البصري
**الخطوات:**
1. افتح `/cinematography-studio`
2. اختر:
   - Noir
   - Realistic
   - Surreal
   - Vintage

**المتوقع:** يتغير نمط الاقتراحات أو الواجهة

---

### CINE-UX-02 — Pre‑Production: توليد الكادر
**الخطوات:**
1. أدخل وصف مشهد
2. اضبط Darkness
3. اضبط Complexity
4. اضغط "توليد الكادر"

**المتوقع:** تظهر اقتراحات Lens وLighting وAngle

---

### CINE-UX-03 — Production: تحليل لقطة
**الخطوات:**
1. ارفع صورة اختبار
2. اضغط Analyze
3. تحقق من:
   - Exposure
   - Grain
   - Mood Fit

**المتوقع:** تحليل واضح للصورة

---

### CINE-UX-04 — الإعدادات التقنية
**الخطوات:**
1. بدّل Focus Peaking
2. بدّل False Color
3. غيّر Color Temperature بين 2000K و10000K

**المتوقع:** القيم تبقى ضمن الحدود

---

### CINE-UX-05 — نظام التحذيرات
**الخطوات:**
1. اطرح سؤالًا تقنيًا
2. تحقق من ظهور رد أو تحذير مناسب

**المتوقع:** رد أو تحذير واضح

---

### CINE-UX-06 — Color Grading
**الخطوات:**
1. اختر نوع المشهد
2. اضبط درجة الحرارة
3. ولّد palette

**المتوقع:** توليد palette ألوان

---

### CINE-UX-07 — Editorial Assistant
**الخطوات:**
1. اكتب ملاحظات مونتاج
2. اضغط Analyze Rhythm

**المتوقع:** تحليل الإيقاع

---

### CINE-UX-08 — Footage Analyzer
**الخطوات:**
1. ارفع فيديو قصير
2. حلله
3. تحقق من:
   - exposure
   - color consistency
   - focus quality
   - motion blur

**المتوقع:** تحليل الفيديو كامل

---

### CINE-UX-09 — Delivery Manager
**الخطوات:**
1. اختر:
   - Cinema DCP
   - Broadcast HD
   - Web/Social
   - Blu-ray
2. تحقق من ظهور codec/resolution الصحيح

**المتوقع:** إعدادات التسليم الصحيحة

---

### CINE-PERF-02 — زمن توليد الكادر
**الخطوات:**
1. سجّل الزمن من الضغط حتى ظهور النتيجة

**المتوقع:** زمن مقبول للتوليد
