# قائمة تحقق الذاكرة الصامتة السريعة

تاريخ الإنشاء:

```text
2026-05-03
```

## المواصفة الأولى

- [x] أمر سياق السؤال لا يطبع سياق الذاكرة كاملًا افتراضيًا.
- [x] أمر سياق السؤال يدعم نمطًا تفصيليًا عند الطلب.
- [x] أمر سياق السؤال يدعم نمطًا صامتًا للخلفية.
- [x] يوجد اختبار يمنع ظهور `memory_context` في الخرج الافتراضي.

## المواصفة الثانية

- [x] بروتوكول البداية يفرق بين بداية الجلسة والسؤال العادي.
- [x] بروتوكول البداية يمنع إعادة التمهيد لكل سؤال عادي داخل نفس الجلسة.
- [x] سياق السؤال الحي يستخدم `--quiet` في مسار الخلفية.
- [x] التحقق الرسمي يفشل إذا غاب شرط الصمت من السياق المولد.

## المواصفة الثالثة

- [x] الأدلة تحفظ في ملف سياق السؤال الحي.
- [x] الأدلة تحفظ في ملف الجلسة.
- [x] أمر التحقق يثبت وجود حقول سياق السؤال.
- [x] الرد الافتراضي لا يحمل تقرير إثبات كامل.

## المواصفة الرابعة

- [x] مراجع تنفيذ الخطة لا يستدعي سياق الدور بلا سؤال.
- [x] مراجع تنفيذ الخطة يستدعي سياق الدور بنمط صامت.
- [x] يوجد اختبار يمنع الاستدعاء غير الصامت.

## حدود متعمدة

- [x] لم يتم حذف قاعدة الذاكرة الدائمة.
- [x] لم يتم حذف PostgreSQL أو Redis أو Weaviate أو Qdrant.
- [x] لم يتم إضعاف فحص قائم.
- [x] لم يتم اعتبار القراءة الساكنة بديلًا للتحقق التنفيذي.
