# معالم منصة النسخة

## الغرض

هذه الوثيقة تحول رؤية المنصة إلى معالم تنفيذية قابلة للقياس.

المعيار الحاكم ليس كثرة الصفحات، بل اكتمال رحلة المستخدم من فكرة أولية إلى ملف إنتاج قابل للاستخدام، مع تحقق تشغيلي واضح قبل إغلاق كل معلم.

## مصادر القرار

- تطبيق الويب الرسمي ومساراته المفعلة.
- الخلفية الرسمية ومسارات الحالة والذكاء الاصطناعي.
- سجل التطبيقات المركزي.
- مواصفة ذاكرة الوكيل الصامتة.
- بحث مستخدم الاستفادة السريعة.
- خط أساس الديون التقنية.

المسارات المرجعية:

```text
README.md
README.ar.md
apps/web/src/config/apps.config.ts
apps/web/src/config/pages.manifest.json
apps/web/docs/API.md
docs/research/quick-value-user-deep-research-2026.md
tech-debt-baseline.json
specs/006-agent-memory-flow/plan.md
```

## تعريف الإغلاق

لا يغلق أي معلم إلا عند تحقق الشروط الآتية:

- مسار نجاح حي للمستخدم.
- مسار فشل حي برسالة مفهومة أو معالجة آمنة.
- تحقق من الربط بين الويب والخلفية عند وجود اتصال.
- تحقق من الحفظ أو التصدير عندما يكون الناتج جزءا من قيمة المعلم.
- عدم زيادة الديون التقنية المجمدة.
- عدم إضعاف أي اختبار أو فحص أو بوابة تحقق.
- توثيق الأدلة في موجز إغلاق المعلم.

| واحد   | قيمة أولى خلال ثلاث دقائق | تجربة فورية بلا إعداد طويل             | مستخدم يخرج بنتيجة قابلة للاستخدام |
| اثنان  | مشروع موحد وحفظ موثوق     | ربط الأدوات حول مشروع واحد             | حالة مشروع محفوظة ومتنقلة          |
| ثلاثة  | رحلة النص الدرامي         | من الفكرة إلى نص قابل للتحرير والتحليل | ملف نص وتحليل مترابطان             |
| أربعة  | رحلة التحضير للإنتاج      | تفكيك وميزانية ورؤية وأزياء ولقطات     | حزمة تحضير إنتاجية                 |
| خمسة   | تشغيل موقع التصوير        | طلبات ومساعدون ومتابعة تنفيذ           | تدفق ميداني قابل للتجربة           |

| سبعة   | جاهزية إطلاق المنصة       | أمان ومراقبة وأداء ونشر                | بوابة إصدار تمر فعليا              |

## المعلم صفر

### الهدف

تثبيت الحقيقة الحالية للمنصة قبل أي توسيع، وفصل ما هو مفعّل وقابل للاستخدام عن التجارب أو المسارات التاريخية.

### النطاق

- جرد التطبيقات المفعلة في المشغل.
- مطابقة المسارات مع ملف المسارات.
- توثيق مسارات الواجهة والخلفية الرسمية.
- تثبيت خط أساس الديون التقنية.
- تحديد الصفحات التي تعتمد على بيانات محلية تاريخية أو مسارات وسيطة.

### مخرجات القبول

- قائمة تطبيقات مفعلة ومتطابقة مع المسارات.
- تقرير ربط بين كل تطبيق ومساراته الخلفية أو المحلية.
- قائمة مخاطر تمنع إطلاق كل تطبيق.
- أوامر تحقق مرجعية لكل طبقة.

### بوابة التحقق

```text
pnpm agent:bootstrap
pnpm agent:verify
pnpm --filter @the-copy/web test:config
pnpm --filter @the-copy/web test:smoke
pnpm --filter @the-copy/backend test:config
```

## المعلم واحد

### الهدف

ضمان أن أول استخدام لأي صفحة رئيسية يعطي قيمة ملموسة خلال أقل من ثلاث دقائق، من غير جدار تسجيل أو إعداد مشروع إجباري.

### النطاق

- محرر السيناريو.
- التفكيك.
- التحليل.
- العصف الذهني.
- الميزانية.
- التصوير السينمائي.
- استوديو المخرج.
- الأزياء.

### مخرجات القبول

- مثال جاهز أو قالب بداية لكل أداة.
- زر نسخ أو تصدير أو حفظ مسودة لكل ناتج مهم.
- حالة فارغة مفيدة في كل صفحة.
- تجربة فشل واضحة عند غياب مفتاح ذكاء اصطناعي أو الخلفية.
- عدم إجبار المستخدم على إنشاء مشروع قبل رؤية أول نتيجة.

### بوابة التحقق

```text
pnpm --filter @the-copy/web test:smoke
pnpm --filter @the-copy/web e2e
pnpm --filter @the-copy/web a11y:ci
```

## المعلم اثنان

### الهدف

تحويل الأدوات من صفحات منفصلة إلى مساحة عمل مشروع واحدة، بحيث ينتقل الناتج بين الأدوات من غير نسخ يدوي أو فقدان سياق.

### النطاق

- نموذج مشروع موحد.
- حفظ حالة التطبيقات عبر الخلفية الرسمية.
- ربط النص بالمشاهد والشخصيات واللقطات والميزانية.
- استعادة المشروع بعد إعادة فتح المتصفح.
- فصل التخزين المحلي المؤقت عن مصدر الحقيقة الرسمي.

### مخرجات القبول

- إنشاء مشروع من تجربة سريعة أو من صفحة المشروع.
- حفظ تلقائي لحالة كل أداة مرتبطة بالمشروع.
- انتقال ناتج التحليل إلى التطوير والتفكيك والميزانية.
- مسار فشل عند انقطاع الخلفية مع احتفاظ مؤقت آمن.
- اختبار تكامل يغطي التنقل بين أداتين على الأقل.

### بوابة التحقق

```text
pnpm --filter @the-copy/web test
pnpm --filter @the-copy/backend test
pnpm --filter @the-copy/web e2e
pnpm type-check
```

## المعلم ثلاثة

### الهدف

تثبيت رحلة النص الدرامي بوصفها قلب المنصة: فكرة، عصف، كتابة، تحليل، تطوير، ومراجعة.

### النطاق

- العصف الذهني متعدد المراحل.
- محرر السيناريو.
- تحليل المحطات السبع.
- مختبر تطوير النص.
- مراجعة النص العربي والأسلوب.
- ذاكرة سياق النص داخل المشروع.

### مخرجات القبول

- بدء فكرة قصيرة وتحويلها إلى مسودة قابلة للتحرير.
- تحليل المسودة وإرسال النتائج إلى التطوير.
- حفظ قرارات التطوير وربطها بالنص.
- إخراج تقرير قابل للنسخ أو التصدير.
- فشل واضح عند نقص المدخلات أو تعطل نموذج الذكاء الاصطناعي.

### بوابة التحقق

```text
pnpm --filter @the-copy/web test
pnpm --filter @the-copy/web e2e -- --grep "brainstorm|analysis|editor|development"
pnpm --filter @the-copy/backend test
```

## المعلم أربعة

### الهدف

تجميع أدوات التحضير للإنتاج في حزمة واحدة قابلة للاستخدام قبل التصوير.

### النطاق

- تفكيك السيناريو.
- الميزانية.
- التصوير السينمائي.
- استوديو المخرج.
- مدير الفن والديكور.
- تصميم الأزياء.
- الممثل الذكي.

### مخرجات القبول

- تحويل نص أو تحليل إلى عناصر إنتاجية.
- ربط العناصر بتقدير تكلفة أولي.
- إنشاء توصيات لقطات أو رؤية تصوير.
- توليد ملاحظات فن أو أزياء قابلة للحفظ.
- إخراج حزمة تحضير تشمل النص والعناصر والتكلفة والرؤية.

### بوابة التحقق

```text
pnpm --filter @the-copy/web test
pnpm --filter @the-copy/web e2e -- --grep "breakdown|budget|cinematography|art-director|styleIST|actorai"
pnpm --filter @the-copy/backend test
pnpm build
```

## المعلم خمسة

### الهدف

تثبيت مسار موقع التصوير والعمليات الميدانية، خصوصا إدارة المساعدين والطلبات، وربطه بما قبل الإنتاج.

### النطاق

- تطبيق إدارة المساعدين والطلبات.
- صلاحيات المستخدمين.
- الطلبات والخرائط والحالة.
- فصل البيانات المالية عن واجهات غير المختصين.
- ربط الطلبات بمشروع أو يوم تصوير.

### مخرجات القبول

- إنشاء طلب ميداني ومتابعة حالته.
- عرض مناسب للدور دون كشف بيانات غير مصرح بها.
- مسار فشل عند فقد صلاحية أو بيانات ناقصة.
- صحة ربط الواجهة بالخلفية أو طبقة الحالة الرسمية.
- تقرير جاهزية خاص بالتطبيق قبل دمجه في إصدار عام.

### بوابة التحقق

```text
pnpm --filter @the-copy/web e2e -- --grep "breakapp"
pnpm --filter @the-copy/web test
pnpm --filter @the-copy/backend test
pnpm agent:verify
```

## المعلم ستة

### الهدف

توحيد ذاكرة الوكلاء والذكاء الاصطناعي بحيث تفهم الأدوات سياق المشروع الحالي دون تسريب داخلي أو اعتماد على ذاكرة الحوار.

### النطاق

- سياق سؤال حي لكل دور.
- أثر محفوظ قابل للتدقيق.
- بوابة إغلاق الجلسة.
- حماية الأسرار.
- مسار سريع صامت للأسئلة العادية.
- ربط الذاكرة بسياق المشروع وليس بمحادثة عابرة.

### مخرجات القبول

- كل سؤال عادي يولد سياقا حيا داخليا.
- الإخراج العادي لا يعرض معرفات أو سياق ذاكرة.
- طلب الإثبات يستخدم أثرا محفوظا فقط.
- فشل التحقق عند غياب حقول حاكمة.
- تقييم زمن المسار السريع وتسجيل التدهور داخليا.

### بوابة التحقق

```text
pnpm exec vitest run scripts/agent/persistent-memory-turn.test.ts scripts/agent/lib/persistent-memory/turn-context.test.ts scripts/agent/lib/persistent-memory/session-store.test.ts scripts/agent/lib/persistent-memory/session-close-gate.test.ts scripts/agent/lib/persistent-memory/evidence-report.test.ts scripts/agent/plan-implementation-reviewer.test.ts
pnpm agent:persistent-memory:turn -- --query "هل المسار العادي صامت؟" --quiet
pnpm agent:persistent-memory:turn:verify
pnpm agent:persistent-memory:eval -- --latency
pnpm agent:verify
```

## المعلم سبعة

### الهدف

الوصول إلى إصدار منصة يمكن الاعتماد عليه، لا مجرد تشغيل محلي ناجح.

### النطاق

- فحص الأنواع والتنسيق والاختبارات والبناء.
- فحص الأسرار والتبعيات والأمان.
- مراقبة الأخطاء والأداء.
- بوابة ميزانيات الأداء والديون.
- توثيق تشغيل ونشر واسترجاع.
- تحقق حي على الويب والخلفية.

### مخرجات القبول

- مرور حزمة التحقق الرسمية.
- تشغيل محلي للويب والخلفية مع مسارات صحة.
- تحقق من مسار نجاح وموت آمن لكل أداة رئيسية.
- عدم وجود أعطال مفتوحة مؤثرة في حالة الجلسة.
- تقرير إصدار يحتوي الأدلة والأوامر والنتائج.

### بوابة التحقق

```text
pnpm validate
pnpm agent:verify
pnpm verify:runtime
pnpm infra:status
```

## مصفوفة التطبيقات

هذه المصفوفة تشمل التطبيقات المفعلة في السجل المركزي كلها.

أما البطاقات الاثنتا عشرة في المشغل الرئيسي فهي واجهة إبراز فقط، وليست حصرا لكل التطبيقات المفعلة.

| التطبيق           | المعلم الأساسي | سبب الربط                        |
| ----------------- | -------------- | -------------------------------- |
| محرر السيناريو    | ثلاثة          | كتابة النص هي مركز الرحلة        |
| العصف الذهني      | ثلاثة          | يبدأ من الفكرة ويولد مادة أولية  |
| التحليل           | ثلاثة          | يحول النص إلى فهم قابل للتطوير   |
| مختبر التطوير     | ثلاثة          | يستخدم التحليل لتحسين النص       |
| الكتابة العربية   | ثلاثة          | يدعم صناعة المسودات العربية      |
| هندسة التوجيهات   | ستة            | يحسن تعليمات الذكاء وسياقه       |
| التفكيك           | أربعة          | يحول النص إلى عناصر إنتاج        |
| الميزانية         | أربعة          | يحول العناصر إلى تكلفة           |
| التصوير السينمائي | أربعة          | يحول المشاهد إلى خطة لقطات       |
| استوديو المخرج    | أربعة          | يجمع الرؤية والمشاهد             |
| مدير الفن         | أربعة          | يحول الرؤية إلى قرارات ديكور     |
| الأزياء           | أربعة          | يحول الشخصيات إلى مظهر إنتاجي    |
| الممثل الذكي      | أربعة          | يدعم الأداء والشخصية قبل التصوير |
| إدارة المساعدين   | خمسة           | يغطي التشغيل أثناء التصوير       |
| لوحة المقاييس     | سبعة           | تقيس الصحة والتشغيل              |

## مؤشرات القياس

| المؤشر                  | حد القبول                   |
| ----------------------- | --------------------------- |
| زمن الوصول لأول نتيجة   | أقل من ثلاث دقائق           |
| حالة فارغة مفيدة        | موجودة في كل أداة رئيسية    |
| قابلية الخروج بالقيمة   | نسخ أو تصدير أو حفظ         |
| مسار فشل مفهوم          | موجود لكل تدفق حرج          |

| تسريب سياق داخلي        | صفر في الإخراج العادي       |

## ما لا يدخل في هذه المعالم

- إعادة تصميم هوية كاملة من الصفر.
- تغيير مدير الحزم أو بنية المستودع.
- إلغاء أي فحص أو اختبار قائم.
- اعتماد تخطيط جوال جديد لواجهات الديسكتوب دون طلب مستقل.
- تهجير قسري لكل أنظمة المعرفة دفعة واحدة.

## موجز الإغلاق المطلوب لكل معلم

يجب أن يحتوي موجز إغلاق أي معلم على:

- تاريخ التنفيذ.
- النطاق المنفذ.
- الملفات أو الوحدات المتغيرة.
- أوامر التحقق التي شغلت فعليا.
- نتيجة كل أمر.
- مسار نجاح حي.
- مسار فشل حي.
- أثر الربط والتكامل.
- ما بقي خارج النطاق بنص واضح.
- درجة الثقة المبنية على التشغيل.
